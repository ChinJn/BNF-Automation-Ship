# BNF Automation — 安裝檔下載

自動走訪包你發（BNF）的老虎機大廳，逐一進入遊戲、掃描座位，並向線上玩家發送訊息。

點下方檔名 → 進入頁面後按右側的 **Download** 按鈕：

### [`BNF-Automation-Setup.exe`](BNF-Automation-Setup.exe)

檔案大小約 **82 MB**。

## 二、安裝

### 執行安裝檔時，Windows 會跳出藍色警告

畫面會顯示「**Windows 已保護您的電腦**」（Windows protected your PC）。

**這是正常的**，因為安裝檔沒有購買數位簽章憑證，並不是病毒。請依下列步驟繼續：

1. 點畫面上的 **其他資訊**（More info）
2. 再點 **仍要執行**（Run anyway）

接著依畫面指示完成安裝（需要系統管理員權限）。

> **安裝完成後，安裝檔會自動刪除。**
> 這是正常設計，不需要自己再刪一次。程式已安裝到電腦中，可從開始功能表或桌面捷徑開啟。

## 三、安裝前必須先準備好（很重要）

### 1. MuMu 模擬器解析度必須設為 **1600 × 900**

**這一項最重要。** 程式的所有座標與畫面辨識都以 1600×900 為基準；解析度不同會造成「找不到遊戲」「偵測不到座位」等看似隨機的錯誤。

設定路徑：MuMu 右上角 **☰ → 設定中心 → 顯示 → 自訂解析度 → 1600 × 900（DPI 240）**

改完請**重新啟動模擬器**。

### 2. 先手動登入包你發一次

在 MuMu 中安裝並開啟《包你發》，**手動登入一次**，確認可以正常進入大廳。
程式不會、也無法代為登入。

---

## 四、每次使用的順序（順序很重要）

1. **先**啟動 MuMu，等它**完全開機**（約 2 分鐘）
2. 在 MuMu 中開啟《包你發》，停在**大廳**畫面
3. **這時候**才開啟 BNF Automation
4. 左側會顯示偵測到的裝置
5. 在 **訊息** 欄位輸入要發送的內容
6. 按 **開始**

> **若顯示「未偵測到 MuMu 裝置」**
> 多半是 BNF Automation 開得太早，MuMu 還沒開機完成。
> 等 MuMu 完全啟動、遊戲停在大廳後，按右上角的 **刷新** 即可，不需要重開程式。

## 五、常見狀況

| 狀況 | 處理方式 |
|---|---|
| 顯示「找不到 MuMu 模擬器 12」 | 畫面上會出現路徑輸入框，按「瀏覽…」選擇 MuMu 的安裝資料夾（包含 `nx_main` 的那一層），按「使用這個資料夾」。設定會自動記住，只需做一次。 |
| 顯示「未偵測到 MuMu 裝置」 | MuMu 尚未開機完成，或遊戲未開啟。處理好後按右上角 **刷新**。 |
| 顯示「輸入法無法使用」 | 在 MuMu 中開啟：「设置」→「系统」→「语言和输入法」→「屏幕键盘」→「管理屏幕键盘」→ 把「**ADB Keyboard**」打開，然後再按一次「開始」。 |
| 執行中畫面卡住不動 | 按 **停止**，確認遊戲仍在前景，再重新開始。 |
| 訊息沒有送出 | 確認帳號具備聊天權限（需銀卡且 50 等以上）。 |

## 六、執行時間參考

預設會掃描 **體驗廳、一般廳、高手廳** 三個館別。

| 項目 | 時間（約略） |
|---|---|
| 每個遊戲（三個館別） | 約 20–30 分鐘 |

時間長短主要取決於**線上玩家人數**，不是遊戲數量 — 玩家越多，要開啟的聊天視窗就越多。空機台翻頁很快，有人的座位每位約需 15 秒。

遊戲數量很多時建議**分批執行**：每次在佇列中放 10–15 個遊戲，跑完再換下一批。
可隨時按 **停止**。

## 七、回報問題

每次執行都會留下一個紀錄檔。回報問題時請附上**最新的那一個**：

```
C:\Users\<您的帳號>\AppData\Roaming\BNF-Automation\logs\
```

紀錄檔裡有判斷原因所需的全部資訊。
